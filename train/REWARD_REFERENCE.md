# MuZero奖励机制 - 快速参考

## 🎯 核心奖励

| 类型 | 分数 | 触发条件 |
|------|------|----------|
| 🏆 **完胜** | **+100,000** | 清空己方球后合法打进黑8 |
| ⚫ **己方进球** | **+1,000/球** | 打进自己的目标球 |
| 🛡️ **安全球** | **+50** | 无犯规无进球 |
| 💀 **致命犯规** | **-4,000** | 白球进袋/非法黑8/失败 |
| 🔴 **破坏** | **-500/球** | 打进对方的球 |
| ⚠️ **首球犯规** | **-500** | 首次击中非目标球 |
| ⛔ **碰库犯规** | **-200** | 无进球且无碰库 |

## 📊 奖励对比

### vs. 旧奖励机制

| 场景 | 旧值 | 新值 | 变化 |
|------|------|------|------|
| 完胜 | +100 | +100,000 | ↑ 1000x |
| 进球 | +50 | +1,000 | ↑ 20x |
| 白球进袋 | -100 | -4,000 | ↑ 40x |
| 首球犯规 | -30 | -500 | ↑ 16.7x |

## 🎮 策略指导

### 优先级
1. **避免致命犯规** (-4,000)
2. **追求完胜** (+100,000)
3. **积极进球** (+1,000/球)
4. **避免破坏** (-500/球)
5. **合法击球** (避免-500犯规)

### 决策树
```
有明确进球机会？
├─ 是 → 进攻 (+1,000)
└─ 否 → 
    ├─ 能安全击球？
    │   ├─ 是 → 安全球 (+50)
    │   └─ 否 → 谨慎选择最小风险
    └─ 避免致命犯规！(-4,000)
```

- **防守平衡**: 50分奖励安全球
- **错误惩罚**: 4,000分警示致命错误

## 📈 评估指标

### 关键指标
- 胜率 (win rate)
- 平均步数 (avg steps)
- 进球率 (pocket rate)
- 犯规率 (foul rate)
- 平均奖励 (avg reward)

### 目标值
- 胜率: > 60% (vs BasicAgent)
- 犯规率: < 10%
- 进球率: > 70%
