# MuZero奖励机制更新说明

## 更新内容

根据提供的图片评分标准，已重新设计MuZero的奖励机制。

## 新的奖励标准

### 1. 致命犯规（缺省-1分）
只要触发以下任何一种情况，分数会被大幅扣减：
- **-4,000分**：白球进袋
- **-4,000分**：非法打进黑8（己方球未清空）
- **-4,000分**：导致游戏失败

### 2. 胜利奖励
- **+100,000分**：完胜对手
  - 在清空自己球后，合法将黑8打进

### 3. 进攻与推进得分
- **+1,000分/球**：打进自己的球
  - 这是AI进攻的主要驱动力
- **-500分/球**：打进对方的球（破坏）
  - 防止AI为了连续球权去破坏对手的球阵

### 4. 击球犯规（扣分，但不一定会输）
这些扣分会被限制，降低其权重：
- **-500分**：首球犯规（没打到自己球或首次碰到对手球）
- **-200分**：本届犯规（无进球且无碰库）

### 5. 安全球奖励
- **+50分**：安全球奖励
  - 既没有犯规也没有进球的情况

## 与原来的区别

### 原来的奖励（analyze_shot_for_reward）
```
+50分/球（己方进球）
+100分（合法黑8）
+10分（合法无进球）
-100分（白球进袋）
-150分（非法黑8）
-30分（首球犯规）
-30分（碰库犯规）
```

### 新的奖励（calculate_muzero_reward）
```
+100,000分（完胜）
+1,000分/球（己方进球）
+50分（安全球）
-4,000分（致命犯规）
-500分/球（打进对方球）
-500分（首球犯规）
-200分（无进球无碰库）
```

## 设计理念

### 1. 大幅提升胜利奖励
- 原来：+100分（黑8）
- 现在：+100,000分（完胜）
- **目的**：让AI明确知道最终目标是赢得游戏

### 2. 提升进球奖励
- 原来：+50分/球
- 现在：+1,000分/球
- **目的**：强化进攻动机，鼓励AI积极进球

### 3. 严厉惩罚致命犯规
- 原来：-100~-150分
- 现在：-4,000分
- **目的**：让AI避免导致失败的错误

### 4. 平衡破坏惩罚
- 新增：-500分/球（打进对方球）
- **目的**：防止AI为了保持球权而故意打进对方球

### 5. 鼓励安全球
- 原来：+10分
- 现在：+50分
- **目的**：在无法进攻时，鼓励打安全球

## 技术实现

### 奖励范围调整
```python
# 配置文件中的范围
VALUE_SUPPORT_MIN = -10000
VALUE_SUPPORT_MAX = 110000
REWARD_SUPPORT_MIN = -5000
REWARD_SUPPORT_MAX = 105000
```

### 网络输出优化
为了避免网络过大，使用固定的bins数量（601个）而不是根据范围计算：
```python
reward_bins = 601  # 固定，不是 105001
value_bins = 601   # 固定，不是 120001
```

### 奖励计算函数
新增 `calculate_muzero_reward()` 函数在 `muzero_train.py` 中：
- 输入：`result`（env.take_shot返回）、`env`、`player`
- 输出：奖励分数（float）
- 实现：根据图片评分标准计算

## 预期效果

使用新的奖励机制后，AI应该表现出：

1. **更强的胜利意识**：明确目标是赢得游戏
2. **更积极的进攻**：主动打进自己的球
3. **更少的犯规**：避免致命错误
4. **更合理的防守**：在无法进攻时打安全球
5. **更少的破坏行为**：不会故意打进对方球

## 注意事项

1. **训练时间**：新的奖励机制可能需要更长的训练时间才能收敛
2. **超参数调整**：可能需要调整学习率、探索参数等
3. **奖励缩放**：如果训练不稳定，可以考虑缩放所有奖励值
4. **价值网络**：价值范围变大，网络需要更多数据才能准确预测
